# Changelog

All notable changes to this project will be documented in this file.

## [0.1.3] - 12-10-2026

### Fixed

- Pasted HTML tables written with indentation no longer get a space at the start of their cells

## [0.1.2] - 12-10-2026

### Changed

- Added a link to the [live demo](https://quill-tablekit.vercel.app/) in the README and docs

## [0.1.1] - 12-10-2026

First release.

- Insert, merge, split, resize, sort and style tables in Quill 2
- Paste tables from Word, Excel, Google Docs and Markdown
- Saved in the normal Quill Delta, clean HTML from `getSemanticHTML()`
